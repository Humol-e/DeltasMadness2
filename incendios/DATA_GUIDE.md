# Data Guide: GeoPulse Wildfires -> Viewer (`sar-platform` / `sar-Madness`)

> This technical guide is maintained in English for NASA Space Apps global judging.

This guide describes every file generated by the `incendios/` pipeline and how it integrates with `sar-platform` / `sar-Madness` while preserving GeoPulse palettes and scientific outputs.

## 1. Pre-generated cases from `geopulse/examples/`

- **`wildfire-palisades-la`** — *Palisades Fire — Los Angeles, CA (2025)* (`2024-12-01/2025-01-06` vs `2025-02-01/2025-03-31`)
- **`wildfire-camp-paradise`** — *Camp Fire — Paradise, CA (2018)* (`2018-09-15/2018-11-07` vs `2018-11-26/2019-01-31`)
- **`wildfire-martin-nv`** — *Martin Fire — Sagebrush Steppe, NV (2018)* (`2018-05-15/2018-07-04` vs `2018-07-25/2018-09-15`)

## 2. Format in `data/downloads/` (GeoTIFF catalog)

Main index: `data/downloads/catalog.json`

Each entry follows the local GeoTIFF catalog schema:

- `local_path`: path to the uncompressed single-band `EPSG:4326` `.tif` readable by `PIL.Image` and `load_geotiff_raster`.
- `asset_name` and `product_layer`:
  - `burn_probability`: continuous probability `[0, 1]` derived from `dNBR`, fuel `NDVI`, and SAR `VH` backscatter drop.
  - `burn_severity`: discrete `uint8` Key & Benson class (`1=low`, `2=moderate-low`, `3=moderate-high`, `4=high`, `0=unburned`, `255=nodata`).
  - `change_probability`: Sentinel-1 + Sentinel-2 multimodal change `[0, 1]`.
  - `uncertainty`: binary entropy and SAR-only zone uncertainty `[0, 1]`.
  - `s2_pre_nbr`, `s2_post_nbr`: pre- and post-fire Normalized Burn Ratio (`NBR`).
  - `s1_pre_vh`, `s1_post_vh`: Sentinel-1 RTC `VH` backscatter in decibels (`dB`).
  - `dem_elevation`: Copernicus 30 m DEM elevation in meters.

## 3. Format in `data/cases/` (3D viewer)

- `data/cases/index.json`: registered case list in `{"cases": ["data/cases/<id>/case.json", ...]}` format.
- `data/cases/<id>/case.json`: camera view (`view`), timeline (*Pre-fire*, *Post-fire (GeoPulse)*, *Severity & Uncertainty*), XYZ raster layers, and GeoJSON vector overlays.
- `data/cases/<id>/tiles/<layer>/{z}/{x}/{y}.png`: pre-rendered 256×256 Web Mercator tiles using the exact GeoPulse color ramps.
- `data/cases/<id>/burn_extent.geojson`: vectorized polygons where `burn_probability >= 0.5` (minimum area `0.002 km²`), styled in `#ffd60a` with black casing.
- `data/cases/<id>/aoi.geojson`: study area boundary polygon.
- `data/cases/<id>/summary.json` and `provenance.json`: burned area metrics (`affected_km2`, `severity_km2`, `review_km2`) and STAC scenes used.
